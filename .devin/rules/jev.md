# Jev の積極利用

推論・判断が求められるユースケースでは、自分の直感だけで決めずに `jev` MCP サーバーのツールを積極的に使うこと。

## 使い分け

- `noul`: yes/no で答えられる判断（確率 0〜1 が返る）
- `choice`: 明示した選択肢キーから1つを選ぶ分類
- `score`: 順序付きレベルでの数値スコアリング
- `run`: 複数の質問をまとめた複合リクエスト

## ユースケース例

- 実装方針・設計の選択肢が複数あり、客観的な判定材料が欲しいとき
- コードやドキュメントの品質・リスクを段階評価したいとき
- 変更が仕様を満たすかの yes/no 判定を定量化したいとき
- ポケモンデータ等の分類・タグ付けの妥当性を判定したいとき

## 注意

- 詳しい使い方は `jev-cli` スキルを参照すること。
- state には判定に必要な情報だけを送り、秘密情報・個人情報は含めない。
- jev の出力は「構造化された判断」であり検証済みの事実ではない。重要な操作は呼び出し側で最終確認する。
